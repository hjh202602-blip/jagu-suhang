# 격자 사냥

마법 학교 견습생이 카드로 행동 순서를 미리 짜고, 마법 탄창 하나로 적을 쓰러뜨리며 미궁을 탈출하는 퍼즐 게임.
2026 1학년 게임개발 프로젝트 (Python + Pygame)

## 실행

```bash
pip install pygame-ce
python main.py      # 게임
python check.py     # 내가 맡은 핵심 기믹을 맞게 만들었는지 확인
```

> Python 3.14 에서는 `pygame` 이 설치되지 않아 `pygame-ce` 를 씀. 코드에서는 똑같이 `import pygame`.

## ★ 팀원이 채울 부분

게임의 틀(화면, 턴 진행, 카드, 맵)은 만들어 두었고, **핵심 자료구조·알고리즘·그림은 비워 두었음.**
빈 함수에는 `todo("...", "담당")` 와 `# TODO(담당 이름)` 주석이 있음. 구현하고 나면 `todo(...)` 줄을 지우면 됨.

| 담당 | 파일 | 채울 것 | 게임에서 쓰이는 곳 |
|---|---|---|---|
| 기획 홍정현 | `structures.py` | `Queue` 클래스 전체 | 행동 큐, BFS |
| 기획 홍정현 | `algorithms.py` | `reverse_queue` (Stack 으로 큐 뒤집기) | 뒤집기 타일 |
| 개발 김보민 | `algorithms.py` | `bfs_path` (BFS 최단 경로) | 적 추격 |
| 표현 주서연 | `structures.py` | `Stack` 클래스 전체 | 마법 탄창, 카드 더미 |
| 표현 주서연 | `algorithms.py` | `selection_sort` (선택 정렬) | 재장전 |
| 표현 주서연 | `assets.py`, `assets/images/` | 그림 에셋 (PNG 넣기 또는 직접 그리기) | 격자, 유닛, 카드 |

**순서**: `Queue` 와 `Stack` 을 먼저. 게임 화면 대부분이 이 둘을 쓰기 때문에, 둘이 비어 있으면 플레이 화면에 들어갈 때 "아직 구현되지 않은 부분" 화면이 나옴.
그다음 BFS·정렬·뒤집기는 비어 있어도 게임은 돌아감. 해당 기능만 "[미구현]" 안내를 띄우고 넘어감.

**확인**: `python check.py` 를 실행하면 담당별로 `[완료] / [미완성] / [오류]` 가 나옴. `[오류]` 면 이유도 같이 나옴.

**규칙 (기획서)**: `collections.deque`, `sort()`, `sorted()`, 길찾기 라이브러리 금지. 직접 구현.

## 조작

| 입력 | 동작 |
|---|---|
| 손패 카드 클릭 | 행동 큐 맨 뒤에 넣기 (최대 5장) |
| 큐 카드 클릭 | 손패로 되돌리기 (실행 전까지만) |
| 실행 버튼 / Enter | 큐 맨 앞부터 하나씩 실행 → 적 차례 |
| R | 이 스테이지 처음부터 |
| ESC | 일시정지 |

## 파일 구조

| 파일 | 내용 | 담당 |
|---|---|---|
| `main.py` | 게임 루프, 화면 전환, 진행 기록 | 개발 김보민 |
| `settings.py` | 화면 크기, 색, 규칙 숫자 | 공용 |
| `todo.py` | 빈 함수 표시 도구 (수정 X) | 공용 |
| `check.py` | 핵심 기믹 채점기 | 공용 |
| **`structures.py`** | **Queue, Stack (빈 칸)** | **홍정현 / 주서연** |
| **`algorithms.py`** | **BFS, 선택 정렬, 큐 뒤집기 (빈 칸)** | **김보민 / 주서연 / 홍정현** |
| **`assets.py`** | **그림 에셋 (임시 글자 그림)** | **주서연** |
| `stages.py` | 스테이지 1~3 맵 | 기획 홍정현 |
| `cards.py` | 카드 6종, 카드 더미/버린 카드 | 기획 홍정현 |
| `battle.py` | 턴 흐름, 카드 효과, 승패 | 기획 홍정현 + 개발 김보민 |
| `board.py` | 격자, 플레이어/적 | 개발 김보민 |
| `magazine.py` | 마법 탄창, 재장전 | 표현 주서연 |
| `ui.py` | 글자, 사각형, 버튼 그리기 | 표현 주서연 |
| `scenes.py` | 타이틀/선택/플레이/일시정지/결과 화면 | 표현 주서연 |

규칙은 `battle.py`, 그리기는 `scenes.py` + `assets.py` 로 나눠 두었음. 화면 코드는 Battle 의 값을 읽기만 함.

## 협업 방법 (기획서 팀 규칙)

1. 작업 전에 `git pull` 로 최신 코드 받기
2. 기능마다 브랜치를 만들어 작업 (예: `git switch -c queue`)
3. 내 담당 파일만 고치고, `python check.py` 로 확인 후 커밋
4. GitHub 에 올리고 Pull Request → 팀원 한 명이 보고 합치기
